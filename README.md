🔍 What is TreeXL?

When working with large datasets, project files, backups, or local archives, converting a folder structure into a structured Excel spreadsheet is often essential.

TreeXL solves this problem with a modern, secure, and high-performance Windows application built with .NET and ClosedXML. It is distributed as an MSIX package, ensuring maximum security, clean installation, sandboxing, and hassle-free uninstallation.

---

🚀 Key Features

* Native Windows Context Menu Integration – Right-click any folder in Windows File Explorer and instantly export its complete directory structure to Excel without opening the main application.
* High-Performance Parallel Scanning Engine – Built with multithreading in C#, TreeXL scans thousands of files and folders in seconds while fully supporting long Windows paths (beyond the traditional 260-character limit).
* Smart Permission Handling – Safely handles "UnauthorizedAccessException" and other access-related errors, allowing protected or system folders to be skipped without interrupting the export process.
* Native Excel (.xlsx) Output – Generates clean, formatted Excel spreadsheets ready for filtering, sorting, reporting, or sharing, powered by the ClosedXML library.
* Secure Distribution (Microsoft Store / MSIX) – No registry clutter, no leftover files, and clean uninstallation managed by the Windows deployment system.

❓ Frequently Asked Questions (FAQ)

How do I export a folder to Excel with TreeXL?

1. Open Windows File Explorer.
2. Right-click the folder you want to export.
3. Select the TreeXL option from the context menu.
4. TreeXL scans the folder hierarchy and automatically generates an Excel spreadsheet containing folders, files, sizes, dates, and file attributes.

What technologies does TreeXL use?

* Programming Language: C# / .NET
* Excel Library: ClosedXML
* Installation Package: MSIX (Compatible with Windows 10 and Windows 11)

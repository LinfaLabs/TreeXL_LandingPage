Using PowerShell

A basic recursive listing can start with Get-ChildItem:

Get-ChildItem "C:\YourFolder" -Recurse | Export-Csv "folder-list.csv" -NoTypeInformation

This is useful for automation, but a CSV is not the same thing as a formatted hierarchical Excel report.

Where scripting becomes work

Depending on the required report, you may need hierarchy logic, formatting, duplicate detection, long-path handling and error handling for inaccessible folders.
